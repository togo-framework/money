# money — docs

Currency-safe money value type for togo (integer minor units).

- **Install:** `togo install togo-framework/money`
- **Marketplace:** https://to-go.dev/plugins/money
- **Source:** https://github.com/togo-framework/money

See [usage.md](usage.md) for constructors, arithmetic, allocation, formatting, JSON/SQL, and FX.
